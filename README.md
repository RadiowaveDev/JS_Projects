# 🚀 JavaScript Fundamentals - Colección de Proyectos Prácticos

## 📋 Descripción General

Bienvenido a esta colección de proyectos diseñada para dominar los fundamentos de JavaScript vanilla. Esta serie de repositorios te guiará desde los conceptos básicos hasta habilidades intermedias, construyendo aplicaciones reales usando únicamente **HTML5, CSS3 y JavaScript puro** (sin frameworks ni librerías).

Cada proyecto incrementa progresivamente en complejidad, permitiéndote consolidar conocimientos mientras creas aplicaciones funcionales y divertidas.

## 🎯 Objetivo de la Colección

- Dominar JavaScript vanilla antes de frameworks como React, Vue o Angular
- Comprender manipulación del DOM sin dependencias externas
- Aplicar conceptos fundamentales: variables, funciones, eventos, estructuras de datos
- Desarrollar lógica de programación mediante proyectos prácticos
- Crear aplicaciones funcionales desde cero
- Establecer bases sólidas para desarrollo web moderno

## 👥 Audiencia Objetivo

Esta colección es ideal para:
- 🎓 Principiantes en programación web
- 💻 Desarrolladores que quieren reforzar fundamentos
- 🔄 Programadores de otros lenguajes aprendiendo JavaScript
- 📚 Estudiantes de bootcamps o cursos de desarrollo web
- 🎯 Autodidactas buscando proyectos prácticos

## 📦 Proyectos de la Colección

### 🧮 Proyecto 1: Calculadora Interactiva

**Dificultad:** ⭐ Principiante  
**Repositorio:** `calculatorJS`

#### ✨ Características Implementadas
- ✅ Operaciones básicas: suma, resta, multiplicación, división
- ✅ Operaciones avanzadas: porcentaje, raíz cuadrada, potencia
- ✅ Botón de limpieza (AC) y borrado (DEL)
- ✅ Soporte para números decimales
- ✅ Historial de operaciones
- ✅ Diseño responsive
- ✅ Teclado numérico funcional
- ✅ Prevención de errores (división por cero)

### ✅ Proyecto 2: Todo List Application
**Dificultad:** ⭐⭐ Principiante-Intermedio  
**Repositorio:** `toDoListJS`

Aplicación completa de gestión de tareas con persistencia de datos.

#### 🎓 Conceptos que Aprenderás
- Arrays y métodos: `push()`, `filter()`, `map()`, `find()`
- Objetos JavaScript y propiedades
- LocalStorage API para persistencia
- JSON: `stringify()` y `parse()`
- Clases y Programación Orientada a Objetos básica
- Métodos de strings
- Date objects y manejo de fechas
- Renderizado dinámico de listas
- Event bubbling y delegation

#### ✨ Características Implementadas
- ✅ Agregar, editar y eliminar tareas
- ✅ Marcar tareas como completadas
- ✅ Filtros: Todas / Activas / Completadas
- ✅ Prioridades: Alta, Media, Baja
- ✅ Fechas de vencimiento
- ✅ Búsqueda de tareas
- ✅ Contador de tareas pendientes
- ✅ Persistencia con LocalStorage
- ✅ Modo oscuro/claro
- ✅ Animaciones CSS

### ⚔️ Proyecto 3: RPG Battle Game
**Dificultad:** ⭐⭐⭐ Intermedio  
**Repositorio:** `simpleRPG`

Juego de rol por turnos con sistema de combate, inventario y progresión.

#### 🎓 Conceptos que Aprenderás
- Programación Orientada a Objetos avanzada
- Herencia y Polimorfismo
- Game loops y estado del juego
- Algoritmos de combate y cálculo de daño
- Generación de números aleatorios (`Math.random()`)
- SetTimeout y SetInterval
- Máquinas de estado (State Machine)
- Animaciones CSS avanzadas
- Módulos ES6 (import/export)

#### ✨ Características Implementadas
- ✅ Sistema de combate por turnos
- ✅ Múltiples clases de personajes (Guerrero, Mago, Arquero)
- ✅ Sistema de habilidades especiales
- ✅ Inventario de ítems y pociones
- ✅ Sistema de experiencia y niveles
- ✅ Tienda de ítems
- ✅ Guardado de progreso
- ✅ Animaciones de batalla
- ✅ Sistema de logros
